# 客户咨询意图分类标准

## 任务

将每条客户咨询归入且仅归入一个二级标签。分类时以用户希望解决的核心问题为准，不能只根据文本中出现的品牌或行业实体判断。

## 标签体系

### 金融/贷款

用户核心诉求涉及个人贷款、房贷、车贷、借贷、信贷额度、贷款条件、贷款利率、首付比例或分期融资方案。

- 包含：贷款申请、贷款利率、房贷、车贷、信贷额度、首付、分期期限。
- 排除：企业融资、股票融资、只讨论车型或车辆价格。
- 正例：公积金贷款利率是多少；买车能贷多少钱。
- 反例：特斯拉融资了多少钱；哪款 SUV 空间大。

### 金融/投资

用户核心诉求涉及基金、股票、债券、理财产品、收益或投资风险。

- 包含：基金申购、股票行情、债券收益、理财风险。
- 排除：个人贷款、企业融资新闻。
- 正例：这只基金近一年收益怎么样。
- 反例：房贷利率能不能打折。

### 汽车/购车

用户核心诉求涉及车型选择、车辆配置、价格比较、试驾或购买决策。

- 包含：车型对比、车辆价格、配置、试驾、购车建议。
- 排除：贷款利率、融资期限、车辆故障维修。
- 正例：预算二十万买哪款 SUV；宝马三系和奔驰 C 级怎么选。
- 反例：汽车贷款首付最低多少。

### 汽车/维修

用户核心诉求涉及车辆故障、维修、保养、配件更换或维修费用。

- 包含：故障灯、保养、轮胎更换、发动机维修。
- 排除：车型购买决策、汽车贷款。
- 正例：发动机故障灯亮了怎么办。
- 反例：哪款车后期保值。

## 边界规则

当“金融/贷款”和“汽车/购车”同时可能成立时：

- 核心诉求是贷款额度、利率、首付比例、分期期限或融资条件，选择“金融/贷款”。
- 核心诉求是车型、车辆价格、配置、试驾或是否值得购买，选择“汽车/购车”。
- 对“汽车金融方案是否划算”但未明确比较价格、利率、期限还是车型价值的情况，当前标准没有规定，不能强行分类。

## 全局优先级原则

1. 明确表达的用户意图优先于通过上下文推断的意图。
2. 用户最终希望完成的行为，优先于 Query 中出现的实体所属行业。
3. 具体业务规则优先于关键词或品牌匹配。
